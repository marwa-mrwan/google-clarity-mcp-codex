# Specialized SEO Reference Packs

These packs extend `seo-strategist` without splitting work across separate skills. Load them only when the task needs the specific capability.

## Packs

- `backlinks/`: backlink quality review, prospecting, free source ideas, risk checks, and disavow caution.
- `local-maps/`: local SEO signals, GBP checks, Maps geo-grid analysis, local schema, and Maps API/free data sources.
- `hreflang/`: international SEO, locale formatting, content parity, cultural adaptation, and translation QA.
- `clusters/`: topical authority, hub-and-spoke planning, SERP overlap, and cluster execution.
- `content-briefs/`: page-type templates, keyword density guidance, excluded domains, and content brief checks.
- `drift/`: content or rankings drift comparison rules.
- `ecommerce/`: marketplace endpoints and Universal Commerce Protocol notes that supplement the main ecommerce reference.
- `google-apis/`: Search Console, GA4, PageSpeed/CrUX, Indexing API, Keyword Planner, NLP, YouTube, auth, and quota notes.
- `schema/`: deprecated schema types and implementation risk checks, supplementing `advanced/schema-types.md`.
- `sxo/`: wireframe templates for search experience and conversion improvements.
- `technical/`: agent-friendly page guidance for crawler and AI assistant accessibility.
- `flow/`: integrated SEO workflow framework and bibliography.
- `premium-report-standard.md`: client-ready reporting standard.
- `shared-data-cache.md`: shared data/cache expectations for multi-step audits.
- `thinking-framework.md`: strategic SEO reasoning framework.
