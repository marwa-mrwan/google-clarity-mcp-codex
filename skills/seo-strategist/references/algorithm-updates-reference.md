# Google Algorithm Updates Reference

## How to Use
1. User reports traffic drop → find the date → match to update below
2. Identify the update type → follow the recovery checklist for that type
3. Never recommend fixes without confirming which update caused the drop

---

## Quick Diagnosis: Traffic Drop Workflow

```
Step 1: Get exact date of traffic drop (GSC → Performance → set date range)
Step 2: Match date to updates table below (±2 weeks)
Step 3: Identify update type
Step 4: Follow recovery checklist for that type
Step 5: If no update matches → check for manual action in GSC
```

## Update Types Explained & Recovery Checklists

### Type 1: Core Update
**What it targets:** Broad quality signals — E-E-A-T, content helpfulness, page experience.
**Recovery timeline:** Must wait for next core update to see recovery (typically 2–6 months).

**Recovery Checklist:**
- [ ] Identify which pages lost rankings (GSC: compare 2 weeks before/after drop)
- [ ] Assess content quality on dropped pages:
  - Is content written by a credible author with demonstrated expertise?
  - Does content answer the query better than competitors ranking above?
  - Is there original research, data, or first-hand experience?
  - Are there factual errors or outdated information?
- [ ] Check E-E-A-T signals:
  - Author bios with credentials
  - About page with company/team info
  - Editorial policy or review process documented
  - External citations to authoritative sources
- [ ] Check page experience:
  - CWV passing on all affected pages?
  - Mobile-friendly?
  - Intrusive interstitials (pop-ups blocking content)?
- [ ] Content depth vs competitors:
  - Are top-ranking competitors covering subtopics you missed?
  - Is content significantly shorter or less comprehensive?
- [ ] Do NOT rush to make changes immediately — diagnose first, then fix systematically

---

### Type 2: Helpful Content Update (HCU)
**What it targets:** Content written for search engines, not people. Affects the entire domain, not just individual pages.
**Recovery timeline:** Slow — domain-level signal takes months to recover. Some sites never fully recover.

**Key signal:** If a large % of your site's content is "unhelpful," ALL pages may be demoted — even good ones.

**Recovery Checklist:**
- [ ] Audit all content — identify pages with zero organic traffic for 6+ months
- [ ] For each low-performing page, ask:
  - Was this written primarily to rank, or to genuinely help a reader?
  - Does it provide a satisfying answer, or does the user need to go elsewhere?
  - Is there first-hand experience, original insight, or unique data?
  - Would a subject-matter expert consider this accurate and useful?
- [ ] Actions per page:
  - Genuinely helpful → keep, improve E-E-A-T signals
  - Thin/SEO-only → rewrite completely with real expertise OR delete + 301
  - Borderline → add first-person experience, data, depth
- [ ] Reduce ratio of unhelpful pages: if >30% of pages are thin/SEO-only, consider mass deletion
- [ ] Add clear author credentials to ALL content
- [ ] Remove or rewrite any AI-generated content that lacks human editing and expertise signals

---

### Type 3: Spam Update
**What it targets:** Cloaking, hacked content, auto-generated spam, site reputation abuse, scaled content abuse, expired domain abuse.

**Recovery Checklist:**
- [ ] Check GSC for Manual Actions first (Search Console → Manual Actions)
- [ ] Scan for hacked content: Google `site:yourdomain.com` — any unfamiliar pages?
- [ ] Check for cloaking: use Google Cache vs what users see
- [ ] Review any third-party content hosted on your domain (site reputation abuse)
- [ ] If using AI for bulk content generation → assess if it passes as genuinely helpful
- [ ] If expired domain was purchased for link building → this will have been devalued
- [ ] If manual action exists → fix the issue → submit reconsideration request in GSC

---

### Type 4: Product/Reviews Update
**What it targets:** Thin affiliate content, review pages lacking first-hand experience, "best X" pages without real testing.

**Recovery Checklist:**
- [ ] Identify all review/comparison/affiliate pages
- [ ] For each page, assess:
  - Is there evidence of first-hand testing or use?
  - Are there original photos, videos, or data from actual use?
  - Are pros AND cons covered honestly (not just positive)?
  - Are comparisons with alternatives included?
  - Is pricing/availability current and accurate?
- [ ] Add to review pages:
  - Author bio with relevant expertise
  - Testing methodology section
  - "Last updated" date
  - Original images (not stock/manufacturer images)
  - Quantitative data where possible

---

### Type 5: Link Spam Update
**What it targets:** Unnatural link profiles — paid links, link schemes, PBNs, low-quality directory spam.

**Recovery Checklist:**
- [ ] Pull full backlink profile (Ahrefs / GSC Links report)
- [ ] Identify toxic patterns:
  - High % of exact-match commercial anchor text from external sites
  - Links from clearly irrelevant sites (e.g., casino sites linking to a food blog)
  - Sudden spike in links from low-DR sites around the same date
  - Site-wide links from a single domain
- [ ] For each suspicious link: try to get it removed (contact site owner)
- [ ] For links that can't be removed: add to disavow file
- [ ] Upload disavow file to GSC (Search Console → Legacy Tools → Disavow)
- [ ] Build high-quality links going forward to dilute the toxic ratio

## No Update Matches the Drop? — Other Causes to Check

| Cause | How to Check | Fix |
|-------|-------------|-----|
| Manual Action | GSC → Manual Actions | Follow specific action guidance + reconsideration |
| Competitor surge | Check who moved up when you moved down | Content quality improvement |
| Technical issue | Crawl errors, accidental noindex, robots.txt change | Technical audit |
| Cannibalization worsened | New page stealing rankings from existing | Cannibalization audit |
| Content decay | Page wasn't updated, competitors updated theirs | Content refresh |
| Lost backlinks | Major referring domain removed links | Link reclamation |
| SERP feature change | Featured snippet or PAA now dominates → zero-click | Restructure for snippet ownership |
