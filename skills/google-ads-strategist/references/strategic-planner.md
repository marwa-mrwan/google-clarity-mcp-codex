## 🔷 Phase 0 — Client Briefing (إلزامي أول حاجة)

> قبل أي كلام تاني، اجمع كل المعلومات دي في محادثة واحدة.

### الأسئلة الإلزامية — اسألها كلها في رسالة واحدة:

```
عشان أبني استراتيجية صح، محتاج أعرف:

📌 البيزنس:
• اسم الشركة / البراند؟
• نوع البيزنس: eCommerce / Lead Gen / Local / SaaS؟
• المنتج أو الخدمة بالتفصيل؟
• السعر أو متوسط سعر الطلب (AOV)؟
• أهم ميزة تنافسية (USP) — ليه العميل يختارك مش المنافس؟

📌 السوق والجمهور:
• الدولة والمدينة المستهدفة؟
• الجمهور المستهدف (عمر / جنس / اهتمامات)؟
• أكبر 3 منافسين؟
• هل البراند معروف ولا جديد في السوق؟

📌 الأهداف والميزانية:
• هدف الحملة الرئيسي (مبيعات / leads / مكالمات)؟
• الميزانية الشهرية أو اليومية والعملة؟
• الـ CPA المستهدف أو ROAS المطلوب؟
• إيه تعريف "النجاح" بالنسبالك؟

📌 البنية التحتية:
• رابط الموقع أو الـ Landing Page؟
• هل في Google Ads account قايم؟ (جديد ولا قديم؟)
• لو قديم: كام conversion/شهر في آخر 90 يوم؟
• نوع التحويل المطلوب (شراء / فورم / مكالمة / واتساب)؟
• هل في CRM أو واتساب automation شغال؟
• هل في customer list (قايمة عملاء حاليين)؟

📌 التاريخ والسياق:
• هل سبق اتعملت حملات Google Ads؟ إيه النتيجة؟
• هل في ميزانية على Meta / TikTok حالياً؟
• الموسم الحالي — بيأثر على مجالك؟
```

## 🔷 Phase 1 — Business Analysis

بعد الـ briefing، حلل البيزنس على 4 محاور:

### 1. Business Type Classification:
```
■ نوع البيزنس:
━━━━━━━━━━━━━━━━━━━━━━
□ eCommerce (منتجات مادية / رقمية)
□ Lead Gen (خدمات / عيادات / تعليم / عقارات)
□ Local Business (موقع جغرافي محدد)
□ SaaS / App (اشتراك شهري / تحميل)
□ Hybrid (مزيج)
━━━━━━━━━━━━━━━━━━━━━━
التصنيف يحدد: نوع الحملة + نوع الـ conversions + الـ bidding strategy
```

### 2. Funnel Stage Analysis:
```
أين البيزنس الآن؟
□ مرحلة الإطلاق (0 data — Brand New)
□ مرحلة النمو (30-200 conv/شهر)
□ مرحلة التوسع (+200 conv/شهر)

هذا يحدد: هل نبدأ بـ Manual CPC ولا Smart Bidding فوراً؟
```

### 3. Competitive Landscape:
```
■ تحليل المنافسة:
• مستوى المنافسة: عالي / متوسط / منخفض
• المنافسون الرئيسيون بيركزوا على إيه؟ (سعر / جودة / سرعة)
• الـ Positioning Gap — فين الفرصة؟
```

### 4. Market Readiness:
```
□ الموقع جاهز للإعلانات؟ (سرعة / landing page / CTA)
□ التتبع مركّب صح؟ (GCLID / Conversions / GA4)
□ الـ offer واضح وجذاب؟
□ هل في social proof؟ (آراء / أرقام / شهادات)
```

## 🔷 Phase 2 — Value Proposition Mapping

> الخطوة دي بتحدد زاوية الإعلانات — مش مجرد كلمات.

### لكل Value Prop، حدد:

```
Value Prop [X]:
━━━━━━━━━━━━━━━━━━━━━━
الـ Pain: [إيه المشكلة اللي بيعاني منها العميل؟]
الـ Value: [إزاي المنتج/الخدمة بتحلها؟]
الـ Proof: [إيه الدليل؟ أرقام / شهادات / ضمان]
الـ Persona: [مين بالظبط صاحب المشكلة دي؟]
الـ Headline: [إزاي نقولها في الإعلان؟]
━━━━━━━━━━━━━━━━━━━━━━
```

### مثال للـ eCommerce (كراسي مكتب):
```
Value Prop 1:
Pain: ظهري بيوجعني بعد 7 ساعات شغل
Value: دعم قطني طبي يخليك تشتغل 10 ساعات مريح
Proof: +500 عميل راضي / ضمان 5 سنين
Persona: موظف Home Office / فريلانسر / مدير
Headline: "اشتغل 10 ساعات بدون ألم ظهر"
```

### مثال للـ Lead Gen (عيادة تجميل):
```
Value Prop 1:
Pain: عمليات التجميل مخيفة ونتايجها مش مضمونة
Value: دكاترة متخصصون + تقنية حديثة + متابعة كاملة
Proof: 2000+ عملية ناجحة / صور حقيقية
Persona: سيدة 25-45 / محترفة / قلقانة من المخاطر
Headline: "نتيجة طبيعية أو مش هتدفعي" ← ⚠️ Policy Check مطلوب
```

## 🔷 Phase 3 — Intent Mapping

> حدد الكلمات والجمهور لكل مرحلة في الـ Funnel.

### الـ 3 مستويات:

**🔴 Bottom of Funnel (BOF) — "المشتري الجاهز"**
```
Persona: عنده المشكلة ومعاه الكريدت كارد
نية: شراء فوري / حجز فوري
نوع الكلمات: [اشتري + اسم المنتج] / [أسعار + الخدمة] / [أقرب + المكان]
Match Type: Exact أو Phrase
الحملة المناسبة: Search BOF / Standard Shopping
```

**🟡 Middle of Funnel (MOF) — "الباحث المقارن"**
```
Persona: بيقارن الخيارات — مش اتقرر بعد
نية: بحث ومقارنة
نوع الكلمات: [أفضل + المجال] / [مقارنة] / [مميزات + الخدمة]
Match Type: Phrase
الحملة المناسبة: Search MOF / Demand Gen
```

**🟢 Top of Funnel (TOF) — "صاحب المشكلة اللي مش عارف الحل"**
```
Persona: عنده الألم بس ما لاقيش الحل لسه
نية: بحث عن معلومات
نوع الكلمات: [مشكلة المجال] / [كيف أحل] / [سبب المشكلة]
الحملة المناسبة: Demand Gen / Display / YouTube
```

### Template الـ Intent Map:

| المرحلة | الـ Persona | مثال كلمات (مصري) | الحملة |
|---|---|---|---|
| BOF | الجاهز للشراء | "اشتري كرسي مكتب مريح" | Search Exact |
| MOF | الباحث المقارن | "أفضل كرسي مكتب بي مصر" | Search Phrase |
| TOF | صاحب المشكلة | "علاج ألم الظهر من الجلوس" | Demand Gen |

## 🔷 Phase 4 — Campaign Architecture Decision

بناءً على الـ Phases السابقة، حدد الهيكل الكامل:

### للـ eCommerce:

```
■ Campaign Architecture — eCommerce:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

المرحلة 1 (0-30 sale):
└── Standard Shopping BOF
    ├── Bidding: Manual CPC
    ├── Ad Group: All Products
    └── هدف: جمع search terms + أول مبيعات

المرحلة 2 (30-50 sale):
├── Standard Shopping BOF (Categorized)
│   └── Bidding: tROAS 1.5
└── Search Brand (لو البراند اتبنى)
    └── Bidding: Max Conversions

المرحلة 3 (+50 sale):
├── PMAX Feed-Only (BOF)
│   └── Bidding: Max Conversions → tROAS
├── PMAX Full-Asset (Best Sellers)
│   └── Bidding: tROAS 1.5-2
└── Demand Gen (MOF/TOF) — بشرط 1000+ customers
    └── Bidding: Max Conversions
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### للـ Lead Gen:

```
■ Campaign Architecture — Lead Gen:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

الحساب الجديد:
└── Search BOF فقط
    ├── Bidding: Manual CPC → Max Conversions بعد 30 lead
    ├── Ad Groups: مقسمة بالـ Value Props
    └── Extensions: Call + Lead Form + Sitelinks

الحساب القديم (+30 conv/شهر):
├── Search BOF (تحسين مستمر)
├── Search MOF (توسيع)
└── PMAX Full-Asset (بشروط):
    ├── Form طويل (أكتر من 3 حقول) أو OTP
    └── Bidding: tCPA (ابدأ بـ 2x الـ CPA الحالي)

الحساب المتقدم (+100 conv/شهر):
├── Search (BOF + MOF + Brand)
├── PMAX
└── Demand Gen (لو في YouTube channel أو 1000+ customers)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 🔷 Phase 5 — 3-Phase Scaling Roadmap

> خطة 90 يوم واضحة للعميل.

```
■ خطة النمو 90 يوم:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📅 الشهر الأول — Stabilise (استقرار):
□ تركيب التتبع صح (GCLID + Conversions + GA4)
□ إطلاق الحملة الأساسية (Search أو Shopping)
□ جمع data بدون تغييرات كتير
□ تحديد أهم search terms وأهم negatives
□ هدف: تحقيق 30+ conversion

📅 الشهر التاني — Optimise (تحسين):
□ تحسين Quality Score للكلمات الأساسية
□ Bid adjustments بناءً على device / time / location
□ إضافة remarketing layer
□ تحسين الـ landing page بناءً على البيانات
□ هدف: تحسين CPA بـ 20-30%

📅 الشهر التالت — Scale (توسيع):
□ توسيع الكلمات (MOF + TOF)
□ تفعيل Smart Bidding (لو +50 conv)
□ إضافة PMAX أو Demand Gen
□ Customer Match من قايمة العملاء
□ هدف: مضاعفة الـ volume مع الحفاظ على CPA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 🔷 Phase 6 — Pre-Launch Checklist

> قبل ما تضغط "Enable" على أي حملة:

```
■ Pre-Launch Checklist:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
التتبع:
□ GCLID Auto-tagging مفعّل
□ Conversion Actions محددة (Primary vs Secondary)
□ Thank You Page موجودة وبتشتغل
□ GA4 ↔ Google Ads Linked
□ Test Conversion شغال

الموقع:
□ Landing Page سرعتها < 3 ثواني
□ CTA واضح above the fold
□ رقم التليفون شغال على موبايل
□ الفورم بيتبعت صح

الحملة:
□ Policy Check اتعمل
□ Negative Keywords محددة
□ Ad Extensions كلها مضافة
□ Budget مش هيخلص قبل الظهر
□ Location targeting صح (مش "Presence OR Interest")
□ Audience Layer مضاف كـ Observation

الإعلانات:
□ كل Ad Group فيه 1 RSA على الأقل
□ Headlines متنوعة (مش كلها نفس الفكرة)
□ Description بيكمّل الـ Headline
□ Final URL بيودي على الصفحة الصح
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
